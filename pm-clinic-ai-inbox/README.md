# PM Clinic AI Inbox Web

Frontend dashboard for PM Clinic AI Inbox.

- Host: Vercel
- Backend/API: Supabase Edge Function `pm-inbox-api`
- Data: Supabase `PM Clinic AI Inbox — Production`
- Branch: `pm-clinic-ai-inbox-web`

The frontend never contains Supabase service-role credentials. Access is authenticated against the backend using a private dashboard access code.
